# SRV Helper | ابزار یکپارچه SSL و مدیریت سرور

نسخه ۱.۰ سورس پروژه، بر پایه آموزش SSL پاسارگارد و با الهام از قابلیت‌های SysHelper و مدیریت DNS/Mirror پروژه Paqet طراحی شده است. **تمام متن‌های محیط تعاملی سرور به فینگلیش نوشته شده‌اند.**

## قابلیت‌ها

- **حالت دستی:** گرفتن یک گواهی برای یک دامنه، مشابه روش قبلی.
- **حالت هوشمند SAN:** گرفتن تنها یک گواهی SSL برای ۲ تا ۲۵ دامنه متفاوت. اعتبارسنجی مالکیت و دسترسی هر دامنه توسط مرجع صدور گواهی ضروری است.
- **حالت هوشمند Batch:** پرسیدن تعداد دامنه‌ها (تا ۵۰ مورد)، دریافت آدرس‌ها، صدور یک‌به‌یک گواهی مستقل، ثبت خطاها و ادامه درخواست‌های بعدی.
- **انتخاب مسیر در پایان:** پاسارگارد، روت یا مسیر دلخواه؛ هر گواهی داخل پوشه جداگانه با نام خودش قرار می‌گیرد.
- **تمدید و انتقال خودکار:** Certbot مسئول تمدید است و hook بعد از تمدید موفق، فایل‌های گواهی را دوباره به مسیر موردنظر انتقال می‌دهد.
- **دسترسی امن:** فایل کلید خصوصی فقط برای root یا یک گروه سرویس مشخص قابل‌خواندن خواهد بود.
- **میرورهای APT اوبونتو:** فهرست ۱۹ میرور ایران و چند گزینه اروپا و آمریکا؛ آزمایش موازی، انتخاب سریع‌ترین پاسخ معتبر، پشتیبان‌گیری و برگشت به تنظیم قبلی.
- **مدیریت DNS:** شکن، رادار، ۴۰۳، الکترو، بگذر، Cloudflare، Google و Quad9 و امکان بازگردانی تنظیم قبلی با systemd-resolved.
- **ابزارهای سیستم:** پردازنده، رم، دیسک، آپتایم، پورت‌ها، IPv6، پاسخ Ping، BBR و نصب‌کننده‌های خارجی 3X-UI و ACME.sh.
- **داشبورد SSL:** فهرست گواهی‌ها، نمایش تاریخ و SAN، آزمایش تمدید و انتقال مجدد گواهی‌های موجود.

## نصب از ZIP

```bash
unzip SRV-Helper.zip
cd SRV-Helper
sudo bash install.sh
sudo srv-helper
```

برای اجرای مستقیم از پوشه بدون نصب:

```bash
sudo bash srv-helper.sh
```

## اجرای GitHub

**این نسخه هنوز به حساب GitHub شما ارسال نشده است.** ابتدا فایل‌های بسته ZIP را در شاخه `main` ریپازیتوری `Amirtn9/srvhelper` جایگزین/آپلود کنید. بعد:

```bash
curl -fsSL -o install-srv-helper.sh https://raw.githubusercontent.com/Amirtn9/srvhelper/main/install.sh
less install-srv-helper.sh
sudo bash install-srv-helper.sh
sudo srv-helper
```

نصب‌کننده برای مخزن `Amirtn9/srvhelper` تنظیم شده است. دستور نصب GitHub پس از آپلود این فایل‌ها در شاخه `main` قابل استفاده خواهد بود. ساخت این ZIP به‌تنهایی تغییری در مخزن GitHub ایجاد نمی‌کند.

## پیش‌نیاز صدور SSL

سرور لینوکسی با دسترسی root، DNS صحیح برای همه دامنه‌ها، امکان ارتباط با Let's Encrypt و آزاد/در دسترس بودن پورت TCP/80 در حالت standalone نیاز است. در حالت webroot باید همه دامنه‌ها به webroot انتخاب‌شده دسترسی HTTP داشته باشند. **گواهی wildcard** در نسخه فعلی پشتیبانی نمی‌شود، زیرا به اعتبارسنجی DNS-01 نیاز دارد.

هنگام استفاده از حالت SAN، منظور از «یک گواهی برای چند دامنه» همان SAN certificate است؛ لازم نیست همه دامنه‌ها متعلق به یک ریشه باشند، ولی تأیید کنترل هرکدام لازم است.

## نکات ایمنی و وضعیت تست

تست‌های ایستا و سنجش ورودی‌ها در این محیط پاس شده‌اند، اما صدور واقعی گواهی، تنظیم mirror و تغییر DNS روی سرور واقعی تست نشده است؛ پیشنهاد می‌شود قبل از محیط عملیاتی، در VPS آزمایشی بررسی شود. مدیریت خودکار mirror در این نسخه **صرفاً برای Ubuntu** اجرا می‌شود، نه Debian. تغییر DNS به `systemd-resolved` فعال نیاز دارد و ممکن است روی بعضی تنظیمات NetworkManager یا DNS دریافتی از DHCP اولویت کامل نداشته باشد.

برای نصب‌کننده‌های خارجی 3X-UI و ACME.sh، فایل از منبع اصلی دانلود می‌شود و فقط پس از تأیید جداگانه اجرا خواهد شد. قبل از اعتماد و اجرای آن‌ها با دسترسی root، کد منبع را بازبینی کنید.
